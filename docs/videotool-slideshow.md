# videotool slideshow

Creates a high quality video slideshow from photos: each photo becomes a short clip with a slow zoom or panorama effect, the clips are cross-faded into each other, and the video fades in and out.

```
videotool slideshow -i <photos and/or directories> [-o <output>] [--resolution <WxH or alias>] [--fps <fps>] [--quality high|medium|low] [--hw_accel auto|on|off]
videotool slideshow -y <file.yaml> [same options]
```

| Option | Description |
|---|---|
| `-i` | Photos and/or directories (processed recursively) |
| `-y`, `--yaml` | YAML file describing the slides, in the format of the file generated by a slideshow (effect and duration of each photo...). The options of the command line take precedence over the ones of the file |
| `-o` | Output video. Default: the name of the first photo, with the video extension |
| `--resolution` | Resolution of the video (aliases accepted, see [resolutions.md](resolutions.md)). Default: `default.slideshow.resolution` (3840x2160) |
| `--fps` | Frame rate of the video. Default: `default.slideshow.fps` (50) |
| `--quality` | Video quality `high` (default), `medium` or `low`, see [quality.md](quality.md) |
| `--hw_accel` | `auto` (default), `on` or `off`, see [hw-accel.md](hw-accel.md) |

A YAML file describing the slideshow is generated next to the video. Its `slideshow` section holds the general parameters (`output`, `resolution`, `fps`, `quality`) and
`photos` the effect of each photo. The paths are relative to the YAML file.
