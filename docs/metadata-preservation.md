# Creation date and geotagging of the generated files

Every media file (video, audio or image) generated by an ffmpeg command of the tools gets the creation date and the
geotagging (GPS coordinates) of the source file it is generated from. The source is the first media file given as input
to ffmpeg (for tools combining several files, like `video-concat`, the first one).

- Creation date: the QuickTime dates (mp4, m4v, mov, m4a...) or the EXIF dates (images) and the date of the file itself
  (modification and creation dates). For the other formats (mkv, mp3, wav...), only the date of the file itself is set.
- Geotagging: the GPS coordinates and altitude, stored in the EXIF tags of images and in the `Keys:GPSCoordinates` tag
  of mp4, m4v, mov and m4a files. Other formats can't hold them.
- Nothing is changed when the source has no date or no GPS coordinates.
- `exiftool` is required. If it is missing or fails, a warning is logged and the generated file is kept as is.

## Files that are not generated by ffmpeg, and files modified in place

- The files generated by the tools that don't use ffmpeg get the dates of their source file too: the PDF files generated by `pdftool`
  (`compress`, `merge` - first input file - and `split`), the copies of files made by `linker` and `audiotool lib`, and the copy of an image
  by `imagetool scale` when the size is unchanged.
- The files modified in place keep their dates: the tags written by `audiotool fix-mp3-meta` and `normalize`, the tags and the album art
  added by the audio tools.
